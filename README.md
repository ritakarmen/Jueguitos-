# 🎮 Jueguitos

Colección responsive de minijuegos desarrollada con **Vue 3 + Vite** como proyecto de portafolio frontend.

## ✨ Juegos incluidos

- 🧠 **Memorama** — encuentra parejas con la menor cantidad de movimientos.
- ⭕ **Tres en raya** — X vs O para dos jugadores.
- ⚡ **Quiz express** — preguntas sobre frontend y Vue.js.
- 🎯 **Prueba de reflejos** — mide tu tiempo de reacción.

## 🛠️ Tecnologías

- Vue 3
- Composition API
- Vue Router
- Vite
- JavaScript
- CSS responsive / mobile-first
- LocalStorage
- GitHub Actions + GitHub Pages

## 📱 Responsive

Diseñado para funcionar correctamente en:

- Celulares
- Tablets
- Desktop

## ▶️ Ejecutar localmente

```bash
npm install
npm run dev
```

## 📦 Build de producción

```bash
npm run build
npm run preview
```

## 🚀 Publicación

El repositorio incluye un workflow en `.github/workflows/deploy.yml` para publicar automáticamente en GitHub Pages.

En GitHub configura:

**Settings → Pages → Build and deployment → Source → GitHub Actions**
